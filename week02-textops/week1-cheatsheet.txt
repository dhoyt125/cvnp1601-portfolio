pwd 
	Flags - N/A
	Example - pwd
	Risk - Prints current path 


ls 
	Flags - -l (Long Format), -a (Show Hidden Files), -h (Human Readable Size Text)
	Example - ls -lh /var/log
	Risk - Read Only, Lists the content of a directory  

cd 

	Flags - cd - , cd .., cd ~, 
	Example - cd /var/log 
	Risk - Very low, can break scripts that assume if the path exist, Changes the current working directory


find 

	Flags - -name, -type, -mtime
	Example - find -name "*.txt"
	Risk - Can be dangerous with -delete, but pretty simple to use, Searches a directory tree for the file with the given criteria

grep 

	Flags - -i, -r, -n, -v 
	Example - grep -i "error" /var/log 
	Risk - Read only, Searches text for lines matching a pattern

head 

	Flags - -n
	Example - head -n 10 file.txt
	Risk - Ready only, Prints the first lines of a file 

wc

	Flags - -l, -w, -c 
	Example - wc -l | grep "*.txt"
	Risk - Read only, Counts lines, or bytes in a file  

Pipe(|)

	Flags - N/A
	Example - ls -la | grep "*.txt"
	Risk - Low, Sends the output of one command into the next command as input 

Redirect(>)

	Flags - None 
	Example - echo "Hello World!" > file.txt 
	Risk - Overwrites the file with no warnings (Lost of data), sends a command output to a file

Append(>>)

	Flags - None
	Example - echo "Hello World!" >> file.txt
	Risk - Safer than ">", sends a command output to a file. adding it after the existing data 

stderr suppression(2>/dev/null)
	Flags - None 
	Example - find -name "*.conf" 2>/dev/null
	Risk - Hides genuine error logs with other expected noise, 
vim
  Flags: none
  Example: vim file.txt
  Risk: Jumping into edits before confirming which mode you're in is a common way to corrupt a file unintentionally.

vim modes & keys
  Flags: none
  Example: i (insert), Esc (normal), :w (write), :q (quit), :wq (save & quit)
  Risk: A stray :w on a config file you don't have permission to safely edit can leave a service misconfigured.

nano
  Flags: none
  Example: nano file.txt
  Risk: It's easy to save changes to a system file out of habit without realizing it's managed by a package or service.

nano save/exit
  Flags: none
  Example: Ctrl+O (save), Enter (confirm), Ctrl+X (exit)
  Risk: Confirming a save on autopilot, without reviewing your edits, can quietly wipe out data you meant to keep.

grep -r
  Flags: -r (recursive)
  Example: grep -r "ssh" /etc
  Risk: Recursive searches can surface file paths and contents you didn't intend to expose, especially in shared environments.

grep -v
  Flags: -v (invert match)
  Example: grep -v "error" /var/log/syslog
  Risk: Filtering out the wrong pattern can silently bury the exact warnings you actually needed to see.

grep -E
  Flags: -E (extended regex)
  Example: grep -E "error|fail" /var/log/syslog
  Risk: A loosely written regex can match far more (or less) than intended, skewing your results.

awk '{print $N}'
  Flags: none
  Example: awk '{print $1, $3}' /var/log/auth.log
  Risk: Grabbing the wrong column index can make log data look correct while actually being mislabeled.

awk -F:
  Flags: -F: (set field separator to colon)
  Example: awk -F: '{print $1, $3}' /etc/passwd
  Risk: Parsing a file like /etc/passwd carelessly can end up displaying more user account detail than necessary.
