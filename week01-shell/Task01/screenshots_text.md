# System orientation screenshots captured and annotated

## /etc
![etc](etc.png)
Contains configuration files that control how programs and services behave.

## /var/log 
![varlog](varlog.png)
Stores system and application log files.

## /tmp
![tmp](tmp.png)
Holds temporary files created by programs.

## /home
![home](home.png)
Personal directories for each user.

## /usr/bin
![usrbin](usrbin.png)
Executable programs and commands for all users.

## Security Note
Configuration files (/etc) show intended system behavior, logs (/var/log) show timeline of what acutally happened, User Data (/home) is showing users activity, Binaries (/usr/bin) is showing what could be executed, Temporary Files (/tmp) is showing data that is being held temporary until reboot. Each of these directories will help answer quetions about what happened and why.
